# CV

Домашние задания по компьютерному зрению.

## Настройка окружения

Нужен [uv](https://docs.astral.sh/uv/).

```sh
uv sync
```

Команда создаёт `.venv/` и устанавливает зависимости.

## Задания

| № | Задача | Данные |
|---|--------|--------|
| 1 | Распознавание цвета сигнала светофора | `hw1/data/` |
| 2 | Границы почки на УЗИ и КТ | `hw2/data/` |
| 3 | Подсчёт кружков преобразованием Хафа | `hw3/data/` |
| 4 | Сшивка кадров в панораму | `hw4/data/` |

### 1. Цвет сигнала светофора

Классический метод без нейросетей: линза ищется по локальному всплеску
яркости (white top-hat), цвет определяется по оттенку в HSV. Дополнительно
учитываются компактные зелёная и красная области, чтобы не путать горящую
линзу с ярким жёлтым корпусом.

Подробное описание метода и параметров — в [hw1/README.md](hw1/README.md).

```sh
uv run python hw1/traffic_lights.py
```

Скрипт раскладывает кадры из `hw1/data/` и записывает имена файлов в
`hw1/red.txt`, `hw1/yellow.txt`, `hw1/green.txt`.

Точность на текущем наборе — 75/75.

### 2. Границы почки на УЗИ и КТ

Для каждого снимка почка выделяется операторами Собеля, Щарра, Прюитта и
Кэнни — отдельно после медианного и после гауссова фильтра. Получается 8 карт
границ на снимок. Результаты сравниваются с эталонной маской почки по F1.

Подробное описание метода, параметров и результатов — в
[hw2/README.md](hw2/README.md).

```sh
uv run python hw2/kidney_edges.py
```

Лучшая комбинация на текущем наборе — гауссов фильтр + оператор Щарра.

### 3. Подсчёт кружков преобразованием Хафа

На снимках брёвен и труб кружки ищутся `cv2.HoughCircles`. Параметры (радиусы,
минимальное расстояние, порог аккумулятора) подобраны отдельно под каждый
снимок, а на кадрах с брёвнами дополнительно отбрасываются тёмные ложные
окружности на листве.

Подробное описание метода, параметров и результатов — в
[hw3/README.md](hw3/README.md).

```sh
uv run python hw3/circles.py
```

Скрипт печатает число кружков по каждому файлу и сохраняет размеченные снимки в
`hw3/output/`.

### 4. Сшивка кадров в панораму

Два решения. Первое (`lab04`) повторяет метод с практического занятия: ORB,
BFMatcher с `NORM_HAMMING`, Lowe ratio 0.6, гомография по RANSAC и перенос
через `warpPerspective`. Второе (`sift`) использует SIFT, `NORM_L2`, ratio 0.75
и преобразование подобия. Оба варианта смешивают кадры с плавными весами.

Подробное описание методов и результатов — в [hw4/README.md](hw4/README.md).

```sh
uv run python hw4/panorama.py              # оба метода
uv run python hw4/panorama.py --method lab04
uv run python hw4/panorama.py --method sift
```

Скрипт сохраняет панорамы в `hw4/output/lab04/` и `hw4/output/sift/`.
