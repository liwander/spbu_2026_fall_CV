# hw2. Границы почки на УЗИ и КТ

## Задача

Написать функцию, которая принимает на вход изображение и возвращает результат
его обработки с помощью оператора Собеля, оператора Щарра, оператора Прюитта и
детектора границ Кэнни. Перед обработкой изображение фильтруется двумя
способами: медианным фильтром и гауссовым фильтром.

На выходе должно получиться 8 обработанных изображений на каждый снимок
(2 фильтра × 4 оператора). В конце нужно указать, какая комбинация
«фильтр + оператор» показывает почку наиболее чётко.

Файл с программой — `hw2/kidney_edges.py`.

## Данные

В `hw2/data/` лежат четыре снимка и четыре маски сегментации:

| Файл | Модальность | Размер |
|------|-------------|--------|
| `img_000001.png` / `mask_000001.png` | УЗИ | 800×800 |
| `img_000027.png` / `mask_000027.png` | УЗИ | 800×800 |
| `img_000032.png` / `mask_000032.png` | УЗИ | 800×800 |
| `img_000036.png` / `mask_000036.png` | КТ | 512×512 |

Все снимки полутоновые. Маска бинарная (`0`/`255`) и показывает, где
расположена почка. Она используется и для наглядности (контур маски
подрисовывается поверх каждого результата), и для объективной оценки.

## Метод

### Функция `process`

`process(image)` принимает полутоновое изображение и возвращает словарь из
восьми карт границ с ключами вида `gaussian_scharr`:

```python
result = process(image)      # -> {"median_sobel": ..., ..., "gaussian_canny": ...}
```

### Предварительная фильтрация

| Фильтр | Реализация | Зачем |
|--------|------------|-------|
| медианный | `cv2.medianBlur`, ядро 5 | убирает импульсный шум (спекл на УЗИ), сохраняет края |
| гауссов | `cv2.GaussianBlur`, σ = 1.5 | мягко подавляет шум, сохраняет слабые протяжённые границы |

### Операторы

| Оператор | Реализация |
|----------|------------|
| Собель | `cv2.Sobel`, ядро 3, модуль градиента `√(Gx²+Gy²)` |
| Щарр | `cv2.Scharr`, модуль градиента |
| Прюитт | в OpenCV нет — свёртка ядром `3×3` через `cv2.filter2D` |
| Кэнни | `cv2.Canny`, пороги от медианы яркости: `0.66·med` и `1.33·med` |

Собель, Щарр и Прюитт дают модуль градиента; он нормируется в `0..255` и
переводится в бинарную карту порогом Оцу. Кэнни сразу возвращает бинарную
карту. Один и тот же порог Оцу для всех градиентных операторов делает сравнение
честным.

### Оценка близости к почке

Контур маски считается правильным ответом. Для каждой карты границ считаются:

- **precision** — доля найденных границ в окрестности почки, которые лежат
  рядом с контуром маски (штрафует реакцию на спекл и посторонние структуры);
- **recall** — доля контура маски, к которому нашлась граница (показывает,
  насколько хорошо очерчена сама почка);
- **F1** — среднее гармоническое precision и recall.

Совпадение считается при расстоянии не больше 4 пикселей. Precision берётся
только по расширенной области почки, чтобы границы других органов и края
датчика не влияли на оценку.

## Результаты

Средний F1 по четырём снимкам:

| Комбинация | Средний F1 |
|------------|-----------:|
| median + sobel | 0.350 |
| median + scharr | 0.338 |
| median + prewitt | 0.361 |
| median + canny | 0.338 |
| **gaussian + sobel** | **0.455** |
| **gaussian + scharr** | **0.455** |
| **gaussian + prewitt** | **0.454** |
| gaussian + canny | 0.323 |

Лучшая комбинация на каждом снимке:

| Снимок | Лучшая комбинация | F1 |
|--------|-------------------|----:|
| `img_000001` (УЗИ) | gaussian + scharr | 0.319 |
| `img_000027` (УЗИ) | gaussian + sobel | 0.343 |
| `img_000032` (УЗИ) | gaussian + scharr | 0.345 |
| `img_000036` (КТ) | median + scharr | 0.818 |

## Вывод

**Наилучшая комбинация — гауссов фильтр + оператор Щарра.** Собель, Щарр и
Прюитт на этих данных работают почти неразличимо (разница в F1 в пределах
0.001–0.003), поэтому между ними выбор непринципиален; формально чуть впереди
Щарр — он точнее по направлению, чем Собель с ядром `3×3`.

Что видно из результатов:

- **Гауссов фильтр лучше медианного** по F1 на УЗИ. Медианный фильтр убирает
  спекл агрессивнее, но вместе с ним «съедает» слабый низкоконтрастный контур
  почки: на `img_000001` recall падает до 0.08. Гауссов фильтр оставляет больше
  деталей, и recall держится на уровне 0.28–0.40.
- **На КТ картина обратная**: контур почки контрастный, и после медианного
  фильтра он получается визуально самым чистым — почти без фоновой сыпи.
- **Кэнни проигрывает** (F1 ≈ 0.32): на УЗИ он срабатывает на каждую крупинку
  спекла, precision падает до 0.14–0.17. На КТ он тоже самый шумный.
- Визуально наименьшее число ложных границ даёт медианный фильтр, а наиболее
  полный контур почки — гауссов. Итоговый выбор (гауссов + Щарр) — компромисс
  в пользу полноты контура на УЗИ, где почку и сложнее всего увидеть.

В папке `hw2/output/` лежат: 8 карт границ на каждый снимок, сводные сетки
`compare_img_*.png` (контур маски подрисован красным), столбчатая диаграмма
`f1_by_combination.png` и таблица всех оценок `scores.csv`.

## Параметры

| Константа | Значение | Смысл |
|-----------|----------|-------|
| `MEDIAN_KSIZE` | 5 | ядро медианного фильтра |
| `GAUSS_SIGMA` | 1.5 | σ гауссова фильтра |
| `MATCH_TOL` | 4 | допуск совпадения границы с контуром, пиксели |
| пороги Кэнни | `0.66·med`, `1.33·med` | автоматические пороги от медианы |

## Запуск

```sh
uv run python hw2/kidney_edges.py
```

Пути можно задать явно:

```sh
uv run python hw2/kidney_edges.py --data hw2/data --out hw2/output
```

Скрипт печатает лучшую комбинацию по каждому снимку и средние оценки, а в
`hw2/output/` складывает 8 карт границ на снимок, сводные сетки и `scores.csv`.
