# hw3. Подсчёт кружков преобразованием Хафа

## Задача

Для каждого изображения подобрать параметры преобразования Хафа и посчитать,
сколько на нём кружочков. Файл с программой — `hw3/circles.py`.

## Данные

| Файл | Что на снимке | Размер |
|------|---------------|--------|
| `logs-1.jpg` | грузовик с брёвнами, вид сзади | 1134×1134 |
| `logs-2.jpg` | тот же грузовик, другой кадр | 1134×1134 |
| `logs-3.jpg` | грузовик с брёвнами издалека | 2268×2268 |
| `logs-4.jpg` | штабель брёвен крупным планом | 514×561 |
| `pipes-4.jpg` | связка серых труб | 556×314 |
| `pipes-5.jpg` | синие и жёлтые трубы на складе | 826×465 |
| `pipes-6.jpg` | крупные гофрированные трубы | 1200×628 |

Кружки — это торцы брёвен и отверстия труб. Снимки сильно различаются
масштабом и размером объектов, поэтому единые параметры не работают: на
`logs-3` брёвна маленькие, на `pipes-6` — крупные.

## Метод

Используются две реализации преобразования Хафа из OpenCV:

| Режим | Функция | Когда применяется |
|-------|---------|-------------------|
| `gradient` | `cv2.HOUGH_GRADIENT` | когда нужно поймать больше мелких кружков |
| `alt` | `cv2.HOUGH_GRADIENT_ALT` | когда на фоне много ложных окружностей |

`HOUGH_GRADIENT_ALT` требует почти идеальной окружности и поэтому чище
отделяет настоящие торцы и отверстия от листвы, бликов и повторяющихся
отверстий. На большинстве снимков он дал заметно меньше ложных срабатываний,
поэтому используется по умолчанию для этой серии. Обычный `HOUGH_GRADIENT`
оставлен для `pipes-5`, где важно поймать больше мелких труб.

### Параметры

Для `HOUGH_GRADIENT`:

```python
cv2.HoughCircles(gray, cv2.HOUGH_GRADIENT, dp=1.2,
                 minDist=..., param1=120, param2=...,
                 minRadius=..., maxRadius=...)
```

Для `HOUGH_GRADIENT_ALT`:

```python
cv2.HoughCircles(gray, cv2.HOUGH_GRADIENT_ALT, dp=1.5,
                 minDist=..., param1=300, param2=...,
                 minRadius=..., maxRadius=...)
```

- `param2` у `HOUGH_GRADIENT` — порог аккумулятора: чем выше, тем меньше
  ложных срабатываний;
- `param2` у `HOUGH_GRADIENT_ALT` — мера «идеальности» окружности (0…1): чем
  ближе к 1, тем строже отбор;
- `minDist` — минимальное расстояние между центрами, чтобы один кружок не
  нашёлся дважды;
- `minRadius`/`maxRadius` — диапазон радиусов под размер объектов на снимке.

Параметры подобраны для каждого снимка отдельно:

| Снимок | Режим | `param2` | `minDist` | радиусы |
|--------|-------|---------:|----------:|---------|
| `logs-1.jpg` | alt | 0.60 | 45 | 15–75 |
| `logs-2.jpg` | alt | 0.60 | 45 | 15–75 |
| `logs-3.jpg` | alt | 0.65 | 14 | 6–18 |
| `logs-4.jpg` | alt | 0.55 | 22 | 12–45 |
| `pipes-4.jpg` | alt | 0.55 | 20 | 10–26 |
| `pipes-5.jpg` | gradient | 40 | 45 | 18–60 |
| `pipes-6.jpg` | alt | 0.60 | 110 | 50–110 |

## Результаты

| Снимок | Режим | Кружков |
|--------|-------|--------:|
| `logs-1.jpg` | alt | 65 |
| `logs-2.jpg` | alt | 56 |
| `logs-3.jpg` | alt | 52 |
| `logs-4.jpg` | alt | 33 |
| `pipes-4.jpg` | alt | 54 |
| `pipes-5.jpg` | gradient | 20 |
| `pipes-6.jpg` | alt | 22 |

Размеченные снимки лежат в `hw3/output/`, все параметры и количество — в
`hw3/output/counts.csv`.

## Замечания

- `HOUGH_GRADIENT_ALT` строже, поэтому на некоторых снимках он находит меньше
  кружков, но почти без ложных: на `logs-4` он перестал реагировать на листву,
  а на `pipes-4` — на тёмные внутренние отверстия и блики.
- На `pipes-5` трубы вложены друг в друга; обычный `HOUGH_GRADIENT` ловит и
  крупные отверстия, и мелкие трубы, поэтому для этого снимка оставлен он.
- На `logs-1` и `logs-2` в кадр попадает машина, на `logs-3` — дальний план;
  единичные ложные срабатывания всё же возможны.

## Запуск

```sh
uv run python hw3/circles.py
```

Пути можно задать явно:

```sh
uv run python hw3/circles.py --data hw3/data --out hw3/output
```

Скрипт печатает число кружков и использованный режим по каждому файлу,
сохраняет размеченные изображения в `hw3/output/` и таблицу `counts.csv`.
