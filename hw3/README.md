# hw3. Подсчёт кружков преобразованием Хафа

## Задача

Для каждого изображения подобрать параметры преобразования Хафа и посчитать,
сколько на нём кружочков. Файл с программой — `hw3/circles.py`.

## Данные

| Файл | Что на снимке | Размер |
|------|---------------|--------|
| `logs-1.jpg` | грузовик с брёвнами, вид сзади | 1134×1134 |
| `logs-2.jpg` | тот же грузовик, другой кадр | 1134×1134 |
| `logs-3.jpg` | грузовик с брёвнами издалека | 2268×2268 |
| `logs-4.jpg` | штабель брёвен крупным планом | 514×561 |
| `pipes-4.jpg` | связка серых труб | 556×314 |
| `pipes-5.jpg` | синие и жёлтые трубы на складе | 826×465 |
| `pipes-6.jpg` | крупные гофрированные трубы | 1200×628 |

Кружки — это торцы брёвен и отверстия труб. Снимки сильно различаются
масштабом и размером объектов, поэтому единые параметры не работают: на
`logs-3` брёвна маленькие, на `pipes-6` — крупные.

## Метод

Используется `cv2.HoughCircles` с методом `HOUGH_GRADIENT`:

```python
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
blur = cv2.medianBlur(gray, 5)
circles = cv2.HoughCircles(blur, cv2.HOUGH_GRADIENT, dp=1.2,
                           minDist=..., param1=120, param2=...,
                           minRadius=..., maxRadius=...)
```

`dp = 1.2` — разрешение аккумулятора, `param1 = 120` — верхний порог Кэнни.
Остальные параметры подобраны для каждого снимка отдельно:

- `param2` — порог аккумулятора: чем выше, тем меньше ложных срабатываний;
- `minDist` — минимальное расстояние между центрами, чтобы один кружок не
  находился дважды;
- `minRadius`/`maxRadius` — диапазон радиусов под размер объектов на снимке.

### Фильтр по яркости

На снимках с брёвнами фон — тёмный лес, и листва даёт много ложных кружков.
Торцы брёвен светлые, поэтому для `logs-1`, `logs-2` и `logs-4` после Хафа
отбрасываются кружки, средняя яркость внутри которых ниже порога. Фильтр
применяется только к этим снимкам; для труб он не нужен.

## Параметры

| Снимок | `param2` | `minDist` | радиусы | порог яркости |
|--------|---------:|----------:|---------|--------------:|
| `logs-1.jpg` | 38 | 45 | 15–75 | 115 |
| `logs-2.jpg` | 38 | 45 | 15–75 | 115 |
| `logs-3.jpg` | 28 | 14 | 6–18 | — |
| `logs-4.jpg` | 30 | 22 | 12–45 | 110 |
| `pipes-4.jpg` | 28 | 20 | 10–26 | — |
| `pipes-5.jpg` | 40 | 45 | 18–60 | — |
| `pipes-6.jpg` | 45 | 110 | 50–110 | — |

## Результаты

| Снимок | Кружков |
|--------|--------:|
| `logs-1.jpg` | 67 |
| `logs-2.jpg` | 67 |
| `logs-3.jpg` | 42 |
| `logs-4.jpg` | 51 |
| `pipes-4.jpg` | 73 |
| `pipes-5.jpg` | 20 |
| `pipes-6.jpg` | 18 |

Размеченные снимки лежат в `hw3/output/`, все параметры и количество — в
`hw3/output/counts.csv`.

## Замечания

- На `logs-1` и `logs-2` в кадр попадают машина и дорожный знак — на них
  приходится несколько ложных кружков.
- На `logs-4` остаётся пара ложных срабатываний на светлых просветах в лесу.
- На `pipes-5` и `pipes-6` трубы вложены друг в друга, поэтому «кружочками»
  считаются внешние отверстия выбранного масштаба; мелкие внутренние трубы
  в счёт не входят — их радиусы выходят за выбранный диапазон.

## Запуск

```sh
uv run python hw3/circles.py
```

Пути можно задать явно:

```sh
uv run python hw3/circles.py --data hw3/data --out hw3/output
```

Скрипт печатает число кружков по каждому файлу, сохраняет размеченные
изображения в `hw3/output/` и таблицу `counts.csv`.
